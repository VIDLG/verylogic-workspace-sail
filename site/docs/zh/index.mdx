# verylogic Sail ISA Workspace

先理解工作区为什么选择可执行 ISA 语言，再选择一个指令集模块，运行它的模型、学习机器契约，并继续理解配套工具。

## 为什么需要 ISA 语言？

Sail 位于架构手册与处理器实现之间：它让指令语义可以执行，又不会把某一种流水线、模拟器或证明系统误当成架构本身。

## 一个 ISA 模块怎样组织

每个模块从概览和教程开始，随后进入 ISA 指南；实现细节较多的 assembler 和 executor 文档统一放在**工具链内部原理**分组。某个 ISA 没有对应工具时，可以省略不适用的页面。
