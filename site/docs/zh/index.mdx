# verylogic Sail ISA Workspace

选择一个指令集模块，运行它的可执行模型，学习机器契约，并继续理解配套工具。

## ISA 模块

### Hack

nand2tetris 使用的 16 位教学计算机。本仓库用 Sail 建模，并提供汇编器、可运行程序、源码断言、Hook 和端到端测试。

- [进入 Hack 概览 →](/zh/hack/)
- [打开 Hack 包参考 →](https://github.com/VIDLG/verylogic-workspace-sail/blob/main/isa/hack/README.zh-CN.md)

## 一个 ISA 模块怎样组织

每个模块从概览和教程开始，随后进入 ISA 指南；实现细节较多的 assembler 和 executor 文档统一放在**工具链内部原理**分组。某个 ISA 没有对应工具时，可以省略不适用的页面。
